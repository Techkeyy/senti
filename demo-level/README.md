# SENTI TEST LEVEL 01: THE CORRIDOR

A tiny, original horror test level built for the Senti demo film. It is a first-person, auto-advancing walk down a dark stone corridor that lasts exactly 2:00 and contains four scripted beats with exact timings, so a designer's intended curve can be compared with a playtester's real reactions.

The level has a built-in story for the demo:

- the designer plans a scare that falls flat (the creaking door): "planned peak, player barely moved";
- an accidental scare in a stretch planned as calm (the thunder crack): "planned calm, player startled";
- a real jump scare lands as planned;
- the boss reveal lands.

## How to play

1. Open `index.html` in Chrome by double-clicking it (works from `file://`, no server, no build step, no network).
2. Click the start screen (the click unlocks audio), then press **F** for fullscreen. Headphones recommended. It contains loud sounds and sudden scares.
3. No input is needed. The level runs exactly 2:00 from the click, then shows "Level complete". Press **R** afterwards to play again.

## Beat timeline (seconds from the start click)

| Time | Beat | What happens |
| --- | --- | --- |
| 0 - 20 | Calm walk | Soft drone, footsteps, torch fades up |
| **22.0** | **Thunder crack** (accidental scare) | Loud thunder sfx, 3 frames of white lightning flash, camera shake, brief light flicker |
| 23 - 44 | Calm | Ambience settles |
| **45 - 55** | **Door creak** (deliberately underwhelming) | A door on the right slowly creaks open, quiet creak sfx, faint shadow in the doorway. No flash, no stinger |
| 56 - 74 | Tension build | Light flickers harder, heartbeat rises, the walk slows, the corridor darkens; lights die at 74.5 |
| **75.0 - 75.6** | **Jump scare** | The pale long-faced creature fills the screen for 0.6 s with a loud stinger, then a hard cut back |
| 76 - 100 | Recovery | Light steadies, ambience calms, footsteps return |
| **105** | **Boss reveal** | The corridor opens into a large dark room, a huge horned silhouette rises with a red rim light and a deep roar. Held about 6 s |
| 112 - 120 | Fade out | Fade to black, then "Level complete" |

## Suggested intended curve for the demo

What a designer who believes the door is the scary part would draw (tension 0-100, time in seconds):

| Time | Tension | Label |
| --- | --- | --- |
| 0 | 15 | calm |
| 40 | 15 | calm |
| 50 | 80 | door creak (the planned peak) |
| 60 | 40 | dip |
| 75 | 95 | jump scare |
| 90 | 30 | recovery |
| 105 | 85 | boss |
| 118 | 20 | end |

Expected Senti flags: the 22 s thunder lands inside the planned calm (planned calm, player startled), the 50 s door is a planned peak where the player barely moves, and the 75 s and 105 s beats match the plan.

## Deterministic capture mode (for filming)

`index.html?capture=1&t=SECONDS` renders the exact frame for time `t` with no audio and no start screen. `window.renderAt(seconds)` is exposed, so a Playwright script can step frames at 30 fps:

```js
await page.goto('file:///.../demo-level/index.html?capture=1&t=0');
await page.waitForFunction('window.__ready');
for (let f = 0; f < 3600; f++) {
  await page.evaluate(t => window.renderAt(t), f / 30);
  await page.locator('canvas').screenshot({ path: `frames/${String(f).padStart(5, '0')}.png` });
}
```

Every frame is a pure function of `t` (seeded hash noise, no unseeded `Math.random`). The canvas is a fixed 1920x1080 and a full frame renders in roughly 5-10 ms. Use a 1920x1080 viewport.

## Files

- `index.html` - the whole level (canvas 2D, plain JS, art drawn in code).
- `sfx/*.mp3` - the seven generated sounds: drone (20 s loop), steps (4 s loop), thunder (3 s), creak (4 s), heartbeat (6 s loop), stinger (2 s), roar (5 s).
- `sfx/sfx.js` - the same sounds as base64, generated by `node build-sfx.js`. `fetch()` is blocked on `file://`, so the page loads audio through this script. Re-run `node build-sfx.js` if you replace any mp3. If it is missing the level falls back to synthesized WebAudio sounds.
